# SolidStart

## Developing

Once you've created a project and installed dependencies with
`deno install --allow-scripts=npm:@parcel/watcher@2.5.1`, start a development
server:

```bash
deno task dev -- --open
```

## Building

```sh
deno task build
deno task start
```
